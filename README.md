# Yacht

A large boat.

### Installing
```
npm i
```

### Running
```
npm start
```

### Consuming in your app
```
npm i yachts
```

```
import yachts from 'yachts';
console.log(yachts);
```

## Built With

* [chalk](https://www.npmjs.com/package/chalk) - terminal string styling
* [figlet](https://www.npmjs.com/package/figlet) - turn a string of text into ASCII art
